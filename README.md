# RAHMAN XEROX & SIFY IWAY - Billing & Shop Management

Offline-first desktop billing application for a Xerox, printing, scanning, and online services shop.

## Tech Stack
- Electron
- React + TypeScript
- Vite
- Tailwind CSS
- SQLite (better-sqlite3)
- Recharts

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run dist
```

## Features
- Fast POS billing
- Service & rate management
- Customer management
- Bills & receipts
- Expense tracking
- Reports & charts
- Backup & restore
- Light/dark mode
- NO GST / NO tax
